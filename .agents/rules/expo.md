# Expo and React Native Rules

*   **Avoid Deprecated Native Packages**: Do not install deprecated native Expo packages (e.g., avoid `expo-av` or similar packages that cause read/build errors in modern environments). Always use packages that are fully compatible with modern Expo.
*   **Avoid Deprecated Methods**: Do not use deprecated React Native or Expo methods. Always refer to the latest documentation.
*   **Industry Standards**: Write code that adheres to current industry standards and modern practices. Avoid outdated or old ways of implementing features.
